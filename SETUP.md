# Install the profile README and Contribution Tetris

1. Extract this ZIP. Its contents are intended for your public profile repository `YASHWANTH-KURAPATI/YASHWANTH-KURAPATI`, not for a new repository.
2. Before uploading, review `assets/Yashwanth-Kurapati-Resume.pdf`. It is your original PDF, unmodified; it includes personal contact details and an email different from the README contact email. A public repository makes it available to anyone.
3. Copy the extracted `README.md`, `assets`, `scripts`, and `.github` into the root of your local clone of the profile repository. Preserve the paths exactly. If using GitHub's website, create `.github/workflows/contribution-tetris.yml` and `scripts/contribution_tetris.py` using **Add file → Create new file** if folder upload omits hidden folders. Keep existing unrelated files and workflows.
4. Commit and push to the default branch. If using GitHub Desktop, review the changes, commit, then Push origin. The workflow may run automatically when its file is added.
5. On GitHub, open the profile repository's **Actions → Contribution Tetris → Run workflow**. Choose the default branch and run. If Actions is disabled, enable it first. The workflow uses the built-in `GITHUB_TOKEN`; no personal access token or external account is required for its normal operation.
6. Once the workflow is green, refresh your GitHub profile. It replaces the initial placeholder graphics with a looping Tetris-style animation and a static graph generated from the GitHub API. The animation plays for about 4 seconds and holds the actual calendar for 3.6 seconds before looping. It refreshes daily (scheduled runs can be delayed).

If the workflow reports a permissions error, check repository **Settings → Actions → General** and any branch protection rules. The workflow needs permission to commit the two generated graphics. If GraphQL rejects the repository token, check the workflow log; the workflow will fail rather than generate fabricated activity. Private activity may not be available with the repository token. No JavaScript is required in the README.
